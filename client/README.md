# Frontend

This directory contains the web dashboard developed for real-time visualization of river pollution monitoring.

## Overview

The frontend is built using **React** and provides an intuitive interface for monitoring predictions generated by the backend. It communicates with the Flask server through REST APIs and Socket.IO.

## Features

- Live dashboard
- Real-time pollution updates
- Image upload interface
- Prediction visualization
- Detection statistics
- Responsive UI
